# 클라우드 컴퓨팅

필요한 컴퓨팅 자원을 서비스로 받아 사용하고 사용량과 계약 조건에 따라 비용을 지불하는 방식입니다. 가상 머신 외에도 관리형 데이터베이스, 컨테이너 실행 환경, 완성된 애플리케이션을 포함합니다.

## 서비스 모델

|구분|사용자가 주로 관리하는 것|예시|
|---|---|---|
|IaaS|OS, 미들웨어, 애플리케이션|Compute Engine, Amazon EC2|
|PaaS|애플리케이션 코드와 데이터|Cloud Run, App Engine|
|SaaS|서비스 설정과 사용 데이터|Google Workspace|

Amazon RDS와 Cloud SQL은 관리형 데이터베이스입니다. 기반 서버가 있다는 이유만으로 사용자가 OS를 관리하는 IaaS로 분류하지 않습니다. Docker와 Kubernetes는 소프트웨어·플랫폼 기술이므로 설치 방식에 따라 사용자의 운영 책임이 달라집니다.

참고: [Google Cloud 서비스 모델](https://cloud.google.com/learn/what-is-iaas), [Amazon RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/)
